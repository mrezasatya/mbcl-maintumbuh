# Referensi (tidak di-deploy)

Folder ini untuk bahan referensi internal pengembang. Isinya **tidak** ikut di-build ke `dist/`
(Vite hanya mem-bundle `src/` dan `public/`) dan **tidak** dikutip atau disebut di antarmuka.

Letakkan lampiran berikut di folder ini secara manual:

| Berkas | Isi | Cara pakai |
|---|---|---|
| `kerangka-kurikulum-hibrida.md` | Kerangka kurikulum hibrida 0 sampai 18 tahun (draf konseptual) | Inspirasi struktur domain |
| PDF *Toddler Montessori* | Daftar kegiatan toddler (appendix, sekitar hlm. 235 sampai 245) | Inspirasi jenis kegiatan; tulis ulang dengan kata sendiri |
| PDF *Cambridge Early Years Handbook 2026* | Aturan administrasi pusat belajar, bukan daftar kegiatan | Konteks saja, jangan disalin |

Semua bahan di atas berhak cipta pihak lain. Pakai hanya sebagai inspirasi, tulis ulang dengan kata
sendiri, dan jangan sebut nama sumber di UI.

> Catatan: saat proyek dibangun, lampiran ini belum tersedia di repositori. Pustaka kegiatan di
> `src/data/activities/` disusun sendiri sebagai panduan stimulasi umum, tanpa menyalin kalimat dari buku
> mana pun. Jika ingin menyimpan PDF berhak cipta di repositori publik, pertimbangkan dulu aspek lisensinya;
> alternatifnya simpan di luar repositori.
